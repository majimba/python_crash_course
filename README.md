# Python Crash Course (3rd Edition) - Learning Repository

This repository contains my code examples, exercises, and projects from [Python Crash Course, 3rd Edition](https://nostarch.com/python-crash-course-3rd-edition) by Eric Matthes.

## Book Structure

The book is divided into two main parts:

### Part I: Basics
- Chapter 1: Getting Started
- Chapter 2: Variables and Simple Data Types
- Chapter 3: Introducing Lists
- Chapter 4: Working with Lists
- Chapter 5: if Statements
- Chapter 6: Dictionaries
- Chapter 7: User Input and while Loops
- Chapter 8: Functions
- Chapter 9: Classes
- Chapter 10: Files and Exceptions
- Chapter 11: Testing Your Code

### Part II: Projects
- Chapters 12-14: Space Invaders-inspired Arcade Game
- Chapters 15-17: Data Visualization
- Chapters 18-20: Web Application with Django

## Repository Structure

```
python_crash_course/
├── basics/           # Part I code examples and exercises
├── projects/         # Part II project files
│   ├── game/        # Space Invaders-inspired game
│   ├── data_viz/    # Data visualization projects
│   └── webapp/      # Django web application
└── resources/       # Additional resources and notes
```

## Development Environment

- Python 3.x
- VS Code (recommended editor)
- Required packages will be listed in `requirements.txt` for each project

## Getting Started

1. Clone this repository
2. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On macOS/Linux
   ```
3. Install required packages for specific projects as needed

## Learning Progress

This repository will be updated as I progress through the book, with commits for each chapter's exercises and projects.
